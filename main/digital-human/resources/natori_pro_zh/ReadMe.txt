
============================================================

Sample model
Natori Shizuku - PRO

============================================================

  This sample can be used to learn advanced production techniques, such as arm switching, which is often used in commercial games and apps.

  The character of this model was designed by the illustrator Senzaki Makoto.
  The model's arms switch between different parts through gradients, a production method often used in commercial games and apps.
  Through this model, you can learn part switching to achieve richer animations.

  In addition, you can use Cubism3 Viewer (for OW) to view the animations of the embedded file groups and understand the data structure used in the complete workflow.
