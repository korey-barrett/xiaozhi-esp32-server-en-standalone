# Project Introduction

manager-api is developed based on the SpringBoot framework.

When developing with a code editor, import the project and select the `manager-api` folder as the project directory.

# Development Environment
JDK 21
Maven 3.8+
MySQL 8.0+
Redis 5.0+
Vue 3.x

# API Documentation
After startup, open: http://localhost:8002/xiaozhi/doc.html
